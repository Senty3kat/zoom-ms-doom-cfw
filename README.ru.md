# Zoom MS Doom CFW

Doom на гитарной педали Zoom MultiStomp: кастомная прошивка для **MS-60B** и
**MS-70CDR**, которая при включении сразу запускает Doom (shareware, эпизод 1) на экране
педали 128×64. Работает на собственном DSP педали TI C674x, 300 МГц. Эффектов в этой
прошивке нет — это отдельная прошивка; чтобы вернуть педаль, прошейте обычный апдейтер.

Статус: работает на настоящей MS-60B (28.10.2026). У MS-70CDR та же плата и ОС; на ней
ещё не запускали. Звука пока нет.

## Безопасность и откат

Загрузчик педали (флеш 0x00000–0x3FFFF) **не пишется никогда**: шаги загрузчика в
апдейтере выключены. Поэтому откат работает всегда:

1. Выключить педаль, зажать **вверх + вниз** (кнопки типа эффекта), включить —
   экран FIRMWARE UPDATE.
2. Запустить стоковый апдейтер Zoom `MS-70CDR v2.10` (или для MS-60B) — вернутся
   прошивка и стоковые эффекты.

Перед прошивкой закрыть Ableton, вкладки браузера с Web MIDI и всё, что держит MIDI-порт
педали. Прошивка идёт заметно дольше обычной: пишется ещё файловая система с Doom.

## Управление

| Орган | В игре | В меню |
|---|---|---|
| крестовина вверх / вниз | вперёд / назад | вверх / вниз |
| крестовина влево / вправо | стрейф | влево / вправо |
| ручка 1 | поворот, 10° на щелчок | влево / вправо |
| ручка 2 | предыдущее / следующее оружие | вверх / вниз |
| ручка 3 | карта вкл / выкл | — |
| нажатие ручки 3 (правой) | огонь | |
| нажатие ручки 1, футсвич | использовать (двери, кнопки) | Enter |
| нажатие ручки 2 | меню (Esc) | Esc |

Бег всегда. Кнопки с антидребезгом; ручки читаются в прерывании GPIO, как в стоковой ОС,
поэтому быстрый поворот не теряет щелчков.

## Сборка

Нужно (в репозиторий не входит):

- TI C6000 CGT 8.5.0 (`cl6x`, ставится с Code Composer Studio) — `TI_CGT_C6000`;
- апдейтер Zoom `ZOOM MS-70CDR v2.10 Updater.exe` (zoom.co.jp) — `ZOOM_UPDATER_70CDR`,
  по умолчанию рядом с `paths.py`;
- `doom1.wad` (shareware 1.9) — `DOOM_WAD`, по умолчанию рядом с `paths.py`;
- Python 3.10+ с Pillow и numpy (только для логотипа).

```bash
git clone --recursive https://github.com/Senty3kat/zoom-ms-doom-cfw.git
cd zoom-ms-doom-cfw
python -I build_cfw.py            # -> out/DialUp-DOOM-ms70cdr-2.10.exe
```

## Как устроено

| Часть | Где | Что |
|---|---|---|
| хук | ОС, `0xC00BB144` | вызов экрана загрузки идёт на трамплин `0xC00F4000` → `doom_hook` |
| загрузчик | Shared RAM `0x80000000` (`loader/`) | логотип; прерывания выкл.; стоп EDMA, McASP, USB; чтение ФС по SPI0; распаковка WAD; переход в Doom |
| Doom | SDRAM `0xC0000000–0xC03FFFFF` | код, данные, стек, куча (зона 2 МБ) |
| WAD | SDRAM `0xC03FF000–0xC07FFFFF` | doom1.wad, распакован загрузчиком |
| экран | `zd_lcd.h` | своя копия последовательности драйвера ОС для ST7565 |
| управление | `zd_pedal.c`, `zd_vectors.asm` | кнопки с антидребезгом, энкодеры в прерывании GPIO банка 1 (INT8) |
| файлы | ФС педали | `DOOM.BIN`, `DOOM.WDZ` (WAD, deflate), пустой `FLST_SEQ.ZDT` |

Doom — [doomgeneric](https://github.com/ozkl/doomgeneric) (подмодуль, без изменений) +
`zd_platform.c` / `zd_pedal.c`. Сначала всё отлажено в эмуляторе педали, потом на железе.
